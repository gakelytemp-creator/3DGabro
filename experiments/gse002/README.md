## Research thesis

Do not seed the learner with the names Box/Cylinder/Sphere/Hole. Start from objects, operations, results, observations and **reusable partitions**. Let a useful relationship found by a probe become a future probe (a new question/column). Prefer cheap symbolic/relational operations and invoke expensive geometric evaluation when necessary. Do not identify reversible information storage with geometric normalization unless an actual canonical representative and reconstruction rule exist.

The central scientific question is whether an agent with a small operator vocabulary can acquire **new reusable operators/partitions** that predict or compress previously unseen structures and improve subsequent experiments—not merely classify training shapes.

## Boundary

- No learned model, synthetic holdout, real scan or GPU job is included.
- Numeric thresholds are not yet frozen; pilots cannot count toward confirmatory results.
- Proprietary/hidden exam instances must not be committed to this public repository. Publish a cryptographic commitment before main runs and disclose the held-out cases only after evaluation.
- This is a proposed **research representation**; it does not claim all real-world quantities can be faithfully reduced to Booleans.
